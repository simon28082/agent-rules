# 发布文末

每篇报告的最后两段必须按以下顺序出现，并都使用斜体。不要在免责声明后追加其他内容。

```markdown
*数据说明：来源：{{关键来源}}；数据截至：{{日期}}；口径差异：{{差异说明或“无重大差异”}}；数据缺口：{{缺口说明或“无”}}*

*本文基于公开资料撰写，仅供研究与交流，不构成任何证券、基金、期权或其他金融产品的投资建议、邀约、推荐或收益保证。文中观点和数据截至文首所示日期，可能随新披露而变化。投资有风险，读者应结合自身目标、风险承受能力及必要时的专业意见独立判断。*
```

生成报告后，必须运行 `scripts/validate-report-footer.py <报告路径>`。校验失败时，修正文末后重新运行。
