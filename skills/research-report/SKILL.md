# 研究报告

## 边界

- 本技能只负责路由、委派、整合、验收、制图与成文。
- 不得直接用 WebSearch、WebFetch、浏览器、抓取脚本或子代理获取外部事实、行情、财务、新闻、行业或估值数据。
- 每项外部事实必须来自下列技能的输出，并保留来源、截至日期、口径和不确定性。没有合格输出则标记“数据缺口”，不得补全、猜测或转引未验证数据。
- 本技能的图表和封面脚本只渲染已验收数据，不获取、计算或推导新数据。
- 交付物是可公开发布的独立分析文章，不是研究底稿或技能执行记录。不得提及 AI、AI Berkshire、技能、代理、工具、命令或内部研究流程。
- 文章遵循所选 reference 的分析框架；语言须自然、具体、基于证据，不写模板化过渡句或均匀罗列。

## 选择路径

1. 出现近期高点回撤 30% 以上、重大利空、业绩/指引失速、监管或诉讼冲击，或用户要求判断“错杀还是陷阱”时，读取 [危机深潜](references/crisis-deep-dive.md)。
2. 其他公司或行业深度研究，读取 [常规深度报告](references/deep-research-report.md)。
3. 危机分析需要完整历史背景时，先按常规路径补齐缺失模块，再以危机路径的结构交付。
4. 信息不足以判断路径时，只询问：公司/标的、研究目的、时间范围、是否存在具体触发事件。

## 委派数据

先写出报告所需的事实清单，再按问题选择最少且足够的技能。向下游技能明确所需时间范围、口径、输出字段及原始来源。

| 所需信息 | 委派技能 |
|---|---|
| 上市公司完整研究；财务、业务、估值、风险 | `investment-research` |
| 需要并行、多视角公司研究 | `investment-team` |
| 管理层、资本配置、治理或接班人 | `management-deep-dive` |
| 未上市公司 | `private-company-research` |
| 长篇公司系列素材 | `deep-company-series` |
| 原始财报、电话会与附注 | `earnings-review` |
| 并行财报解读 | `earnings-team` |
| 行业、产业链、竞争格局 | `industry-research` |
| 行业筛选、候选池收敛 | `industry-funnel` |
| 排除低质量标的 | `quality-screen` |
| 供应链物理瓶颈 | `bottleneck-hunter` |
| 买入前快速检查 | `investment-checklist` |
| 组合、仓位、再平衡 | `portfolio-review` |
| 已有投资论文的持续跟踪 | `thesis-tracker` |
| 两份论文/报告的变化辨析 | `thesis-drift` |
| 近期股价异动和事件归因 | `news-pulse` |
| 财务数据、历史价格、估值和审计抽检 | `financial-data` |

委派规则：

- 财务或估值数据必须包含 `financial-data` 的交叉验证结果；报告仅采用已验证结果。
- 近期事件优先委派 `news-pulse`；原始财报细节优先委派 `earnings-review` 或 `earnings-team`。
- 若需要某项指标而表中没有明显对应技能，要求最接近的研究技能补充；该技能无法提供时记录数据缺口。
- 不把下游输出未经检查地并入报告：拒绝缺少来源、日期、口径或与其他输出矛盾且未解释的结论。

分析辅助可使用 `dyp-ask`；其输出不得单独作为任何外部事实的来源。

## 整合与验收

1. 建立“事实—来源—口径—适用章节”清单，仅写入已验收事实。
2. 财务、估值和审计结论仅接受下游技能已经提供的交叉验证结果。
3. 验收不通过时，要求下游技能补充或修正；无法证实的表述必须删除。

## 制作与交付

- 报告必须生成封面：使用 `templates/cover.html` 和 `scripts/gen-covers.sh`，以已验收数据填充封面指标，并将 `cover.png` 放在标题后、正文前。
- 图表数据只能来自验收后的事实清单；使用 `scripts/gen-charts.py` 输出到报告同级 `charts/`。
- 最终文章不得使用 Markdown 表格。比较型或摘要型信息使用 `table` 子命令生成 PNG；趋势、结构和关系信息使用相应图表。
- 收入或业务结构金额可靠时，使用 `pie --amount-and-percentage --amount-unit B`，在同一图中展示每项业务收入与占比；仅有占比时才使用 `pie --percentage`。
- 图表和表格图片紧跟首次解释该数据的段落；同一位置连续放置不超过两张图片，避免集中堆放在单一章节。
- 图片不写数据校验过程、准确率或验证结论；正文末尾先集中列出关键来源、数据截至日期、口径差异和数据缺口。
- 所有报告的最后一段必须固定加入：本文基于公开资料撰写，仅供研究与交流，不构成任何证券、基金、期权或其他金融产品的投资建议、邀约、推荐或收益保证。文中观点和数据截至文首所示日期，可能随新披露而变化。投资有风险，读者应结合自身目标、风险承受能力及必要时的专业意见独立判断。
- 保存位置由用户指定；未指定时先询问。不得擅自覆盖既有报告。
- 写作和章节结构以所选 reference 为准；reference 仅定义报告形态，不得覆盖本文件的数据边界。
